# My Trip Planner

אפליקציית Web לניהול ותכנון טיולים בחו״ל — מסלול יומי, מפה, מלונות, טיסות, רכב, מסמכים ותקציב,
הכל במקום אחד. בנויה Mobile First, עובדת מצוין בטלפון, בטאבלט ובדסקטופ, ונשמרת מקומית כך שהיא
זמינה גם בלי רשת בזמן הטיול.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # ייצוא סטטי לתיקיית out/
npm run typecheck
npm run lint
```

בכניסה הראשונה נטען אוטומטית טיול הדגמה מלא — **צפון יוון, אוגוסט 2026** — עם 14 ימים,
93 פעילויות, 5 מלונות, טיסות, רכב שכור, רשימת מקומות, מסמכים, צ׳קליסטים והוצאות, כדי שכל מסך
יהיה ניתן לבדיקה מיד.

## הטכנולוגיה

- **Next.js 16** (App Router) + **React 19** + **TypeScript** — `output: 'export'`, כלומר הבילד הוא
  אתר סטטי שאפשר לארח בכל מקום.
- **Tailwind CSS v4** — Design tokens ב-CSS, מצב בהיר וכהה, RTL מלא באמצעות logical properties.
- **Zustand** — ניהול מצב עם undo, ושמירה אוטומטית (debounced) דרך שכבת ה-repository.
- **dnd-kit** — Drag & Drop במסלול ובמסך המקומות, כולל תמיכה במגע ובמקלדת.
- **Leaflet / react-leaflet** — מפה אינטראקטיבית ללא צורך במפתח API.
- **Recharts** — גרפי התקציב.
- **idb** — קבצי מסמכים ב-IndexedDB.

### שכבות אבסטרקציה ל-API חיצוני

האפליקציה עובדת במלואה בלי אף שירות חיצוני. כל נקודה שבה *אפשר* לחבר API אמיתי עטופה
בממשק, כך שההחלפה היא מימוש אחד ולא שינוי במסכים:

| שירות | ברירת מחדל (ללא רשת) | חלופה מקוונת | הממשק |
| --- | --- | --- | --- |
| התמדה | `LocalStorageRepository` | Supabase / Postgres | `TripRepository` (`lib/db/repository.ts`) |
| זמני נסיעה | הערכה מקומית לפי מרחק וסוג דרך | OSRM | `RoutingProvider` (`lib/services/routing.ts`) |
| שערי מטבע | טבלת שערים ידנית | frankfurter.dev (ECB) | `RatesProvider` (`lib/services/currency.ts`) |
| חיפוש מקומות | קטלוג מקומי | OpenStreetMap Nominatim | `SearchProvider` (`lib/services/places-search.ts`) |
| עוזר AI | מנוע דטרמיניסטי מעל נתוני הטיול | מודל שפה | `AssistantProvider` (`lib/services/assistant.ts`) |

הניתוב המקוון וחיפוש המקומות המקוון כבויים כברירת מחדל וניתן להדליק אותם בהגדרות.

### מעבר ל-Supabase

1. לממש `TripRepository` מול הטבלאות שב-[`docs/DATA_MODEL.md`](docs/DATA_MODEL.md).
2. להחליף שורה אחת ב-`src/lib/db/index.ts`.
3. להסיר `output: 'export'` מ-`next.config.ts` אם רוצים אימות בצד השרת.

## נתונים ופרטיות

כל הנתונים נשמרים בדפדפן של המכשיר בלבד:

- נתוני הטיול — `localStorage` תחת המפתח `mtp:data:v1`.
- קבצי מסמכים — IndexedDB (`mtp-files`), כדי לא לפוצץ את מכסת ה-localStorage.
- העדפות תצוגה — `mtp:settings:v1`.

שום מידע לא נשלח לשרת. בהגדרות יש **ייצוא גיבוי** ו**ייבוא גיבוי** בפורמט JSON — זו גם הדרך
להעביר טיול בין מכשירים, ולשתף אותו עם מישהו אחר עד שיחובר שרת.

## הערות מוצר

- **Undo** — כל פעולה הרסנית מציגה Toast עם ״בטל״, ובנוסף יש כפתור Undo קבוע בכותרת.
- **מחיקה** — תמיד עם דיאלוג אישור שמסביר מה בדיוק יימחק.
- **Empty states** — לכל מסך יש מצב ריק עם הסבר וכפתור פעולה.
- **אזהרות זמן** — כשזמן הנסיעה המשוער ארוך מהפער בין שתי פעילויות, המסלול מסמן את המעבר
  ומציין בכמה דקות חסרות. (בטיול ההדגמה יש מעבר כזה ביום 10, בין חוף קארידי לקבורוטריפס.)
- **מטבעות** — כל סכום נשמר במטבע המקורי שלו ומוצג לצידו הערך במטבע הטיול.
- **נגישות** — ניווט מקלדת, `aria-*` על כל הפקדים, מלכודת פוקוס בחלונות, כיבוד
  `prefers-reduced-motion`.
